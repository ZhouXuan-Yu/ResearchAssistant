## 数据集标识：`<短名>-<版本>`

| 字段 | 内容 |
|---|---|
| **名称** | |
| **类型** | 原始 / 整理 / 标注 / 派生 |
| **来源** | 机构 / 出版物 / 数据库 / URL（尽量到版本级） |
| **许可与可用范围** | 许可证名称；是否允许再分发；是否允许商用；引用要求 |
| **规模** | 条目数 / 字数 / 图像数 / 标注数 |
| **字段与格式** | 列名或 schema；文件格式 |
| **获取日期** | YYYY-MM-DD |
| **数据版本** | 语义化版本；若来源无版本，用获取日期 + 校验和 |
| **校验和** | sha256（对归档文件） |
| **质量与已知问题** | 缺失、噪声、口径变化、已知错误 |
| **出处可信度** | 证据等级 F/L/I/U + 说明 |
| **关联** | 相关实验 / 论文 / ADR 编号 |
| **责任人** | |
| **存放位置** | 目录或归档路径 |
