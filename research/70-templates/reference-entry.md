## 引用条目

| 字段 | 内容 |
|---|---|
| **标题** | |
| **作者** | 全部作者，或"等" |
| **年份** | |
| **发表处** | 期刊/会议/出版方 + 卷期页 |
| **DOI / URL** | |
| **标识符** | arXiv / PMID / ISBN 等 |
| **核验状态** | 已核对正文 / 仅读摘要 / 仅见于二手 / 未核验 |
| **事实 vs 观点** | 该文献报告的是实验事实，还是作者主张 |
| **支撑的论断** | 我在稿件里用它支撑哪句话（原文引用该句） |
| **吻合度** | 该文献是否真的支持我的论断（是 / 部分 / 否 / 未检查） |
| **证据等级** | F / L / I / U |
| **备注** | 反面证据、限制条件、与他人结果的冲突 |
