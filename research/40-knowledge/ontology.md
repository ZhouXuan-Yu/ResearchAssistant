# 本体 / Schema（Knowledge Layer）

> 建立：2026-09-18｜状态：**骨架待定**
> 本层定义"领域里有哪些实体与关系"，是知识图谱与检索增强的共同地基。

## 设计原则

1. **先对齐再自造**：优先复用成熟本体（如 CIDOC-CRM、已有文物/古籍本体），说明对齐关系；确需扩展时显式标注为扩展。
2. **关系要带出处**：每条三元组记录来源与置信度，不做无源断言。
3. **可演进**：schema 有版本号；变更记录在案。
4. **区分事实与释读**：物质属性（出土位置、尺寸）与学术释读（释义、断代）分属不同关系，置信度口径不同。

## schema 必须包含

| 项 | 说明 |
|---|---|
| 实体类型 | 完整枚举 + 定义 |
| 关系类型 | 定义 + 方向 + 基数 |
| 属性 | 类型、取值范围、单位 |
| 出处模型 | 每个断言的来源与置信度 |
| 版本 | schema 版本与迁移说明 |
