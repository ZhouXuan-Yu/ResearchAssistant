# 标注规范（Annotation Guidelines）

> 版本：**v0.1（待研究方向确定后细化）**｜建立：2026-09-18
> 本层负责"把原始材料变成可计算的监督信号"。规范不定稿，不允许开始大规模标注。

## 规范必须包含的要素

| 要素 | 要求 |
|---|---|
| 标注单元 | 明确到字/词/句/段还是条目 |
| 标签体系 | 完整枚举 + 定义 + 边界例 + 反例 |
| 歧义处理 | 遇到无法判断时如何标记（如 `uncertain`），不得强选 |
| 置信度 | 每条标注附置信度（高/中/低）与理由 |
| 来源标注 | 释读/释义的出处（作者、出版物、页码） |
| 残缺处理 | 缺字、残损的统一记法 |
| 版本 | 规范本身有版本号；规范变更需重标或标注适用版本 |

## 一致性要求

- **双人标注**：至少两名标注者独立标注一个子集。
- **一致性指标**：分类任务报 Cohen's κ；多标注者报 Krippendorff's α；连续量报 ICC。
- **门槛**：κ/α < 0.7 时先修规范，不进入训练。
- **抽检**：每批标注抽检 ≥10%，记录错误率。

## 交付物

1. `guidelines.md`（本文件，规范正文）
2. `schema/`（标签定义文件，机器可读）
3. `ia-report.md`（一致性报告）
4. 标注数据本身（登记进 `10-data/registry.md`）
