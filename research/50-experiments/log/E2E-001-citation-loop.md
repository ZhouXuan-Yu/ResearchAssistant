## 实验：F7 端到端闭环 ｜ 日期：2026-09-18

### 1. 目的与假设

- 目的：验证"获取 → 解析 → 核验 → 记录 → 治理登记 → 质量门禁"闭环可否跑通且可复现。
- 假设：给定一份公开材料，流程能在不依赖任何秦简内容的前提下完整走通，且每一步都留下可回溯记录。
- 判决标准：六步全部产出可核查记录，且质量门禁（G1/G4/G5）不报警。

- 材料：arXiv:1706.03762（*Attention Is All You Need*），公开页面
- 许可：arXiv non-exclusive license
- 与研究方向无关（非秦简），符合 F7 要求

```
① 获取  web_fetch https://arxiv.org/abs/1706.03762
② 解析  提取 标题/作者/年份/标识符/DOI/许可/实验数值
③ 核验  G1：以官方 abs 页为主源核对元数据；标注未核对项
④ 记录  写入 research/60-writing/references.md（R-001）

⑥ 门禁  检查 G1/G4/G5
⑦ 回滚演练  副本损坏 → 从快照恢复 → 逐字节比对
```
