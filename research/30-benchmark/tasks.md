# 评测任务定义（Benchmark Tasks）

> 建立：2026-09-18｜状态：**任务待定义**
> 没有固定评测的领域，无法判断方法是否真的更好。本层是研究结论的**裁判**。

## 每个任务必须定义

| 字段 | 要求 |
|---|---|
| 任务名 | 唯一标识 |
| 输入 / 输出 | 严格格式 |
| 评价指标 | 主指标 + 辅助指标；指标的适用条件与失效场景 |
| 数据划分 | train/dev/test 固定，划分脚本可复现，禁止泄漏 |
| 金标来源 | 专家标注 / 权威版本 / 人工核验；标注者资质 |
| 基线 | 强基线 ≥2 个（含现成方法），可复现 |
| 显著性 | 报置信区间与检验方法；多重比较需校正 |
| 失败模式 | 明确任务不擅长什么 |

## 反作弊清单

- [ ] 测试集未参与任何调参
- [ ] 训练/测试无实体重叠（防记忆）
- [ ] 报告多次运行方差，不只报最好一次
- [ ] 指标口径与基线一致
- [ ] 数据来源与许可可追溯
