# 科研工作区（Research Workspace）

> 建立：2026-09-18｜维护：科研助手（agent-mu42qzfz）｜状态：**方向无关骨架，待研究方向确定后填充**
> 本目录是所有正式科研资产的落地位置。`foundation/` 放基础设施，本目录放研究本身。

## 为什么这样分

科研的失败大多不是"方法不好"，而是**来源不清、版本不明、结论越界**。所以这里按"证据产生的顺序"分层，每层都有登记表，让任何一条结论都能回溯到它的数据、代码与文献。

## 目录约定

| 目录 | 放什么 | 必须有 |
|---|---|---|
| `00-governance/` | 决策记录（ADR）、变更日志 | 每个决策有编号、理由、回滚方式 |
| `10-data/` | 数据资产与登记表 | 每个数据集登记来源与**许可** |
| `20-annotation/` | 标注规范、标注一致性记录 | 规范版本号 + 一致性指标 |
| `30-benchmark/` | 评测任务定义、金标集 | 任务可复现、划分固定 |
| `40-knowledge/` | 本体 / schema / 图谱 | 与既有本体对齐说明 |
| `50-experiments/` | 实验日志 | 代码版本、随机种子、失败也记录 |
| `60-writing/` | 稿件、引用登记 | 引用核验状态 |
| `70-templates/` | 各类记录模板 | — |

## 证据等级（贯穿全部记录）

任何结论、数字、判断，都必须落在以下四档之一，禁止含混：

| 等级 | 含义 | 写法 |
|---|---|---|
| **F** 事实 | 我或你可直接验证的观测 | 附命令/文件/截图 |
| **L** 文献 | 来自论文/标准/官方文档 | 附 DOI 或 URL + 版本 |
| **I** 推断 | 由已知推出的合理判断 | 显式写"推断"，并给依据 |
| **U** 未知 | 无法核验 | 写"待确认"，禁止补全 |

## 使用规则

1. 新增数据 → 先填 `10-data/registry.md`，再放文件。
2. 跑实验 → 先开日志（用模板），失败与异常必须写。
3. 做重要选择 → 写 ADR。
4. 引用文献 → 填 `60-writing/references.md`，标注核验状态。
5. 任何改动 → 记 `00-governance/changelog.md`。
