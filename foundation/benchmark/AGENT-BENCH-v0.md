# 科研智能体评测基准 v0（AGENT-BENCH-v0）

> 建立：2026-09-18｜维护：agent-mu42qzfz｜状态：**任务已定义，尚未执行首轮**
> 版本：**v0（冻结）**。冻结含义：任务、真值、判据一经执行不得随手改动；修改须走 ADR。

## 这个基准评什么

评**智能体自身的研究支撑能力**，不评研究方向本身。

- 本文件：评"这个智能体是否可靠"（检索、核验、精读、诚信、纪律）
- `research/30-benchmark/tasks.md`：评"秦简方向的方法是否更好"（方向确定后才建）

两者不可混用。

## 为什么自建，而不是用 PaperBench 一类基准

据此前调研（来源为公开论文，**未在本轮二次核验**）：PaperBench（OpenAI）类基准要求从零复现若干篇 ICML 论文，成本高、周期长、依赖 GPU 与大额 token 预算，**不适合作为日常回归**。

自建 v0 的设计取舍：**便宜、可重复、真值硬**——目标是"每周能跑一遍且结论可信"，而非"最接近人类科研全貌"。

## 设计原则

1. **真值必须外部可核**：真值来自权威数据库（CrossRef/arXiv）或本机事实，不来自我的判断。
2. **可重复**：同样输入、同样工具，结论应稳定；波动本身是信号。
3. **禁止补全**：任何"编造以通过测试"的行为触发一票否决。
4. **有病历**：失败必须记录失败模式，不只记分数。
5. **低成本**：全量一轮 ≤ 40 次工具调用、≤ 15 分钟。

## 已知局限（v0 自认不覆盖）

- 不评估**长周期**任务（多周实验、投稿全流程）。
- 不评估**开放研究判断**（选题质量、方法创新度）——这类只能人评。
- 不覆盖 Scopus / ScienceDirect（未配置 Elsevier），故 T-01/T-05 只走免密钥源。
- Zotero 库仅 1 条目（2026-09-18），T-06 的区分度低；库增长后须重设真值。
