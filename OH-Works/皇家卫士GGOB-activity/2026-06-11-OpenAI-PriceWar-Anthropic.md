# OpenAI 酝酿大幅降价，AI 价格战升温

**时间**: 2026-06-11 | **来源**: WSJ / Reuters

## 核心信息

OpenAI 正在考虑大幅下调 token 定价，以从 Anthropic（Claude）手中争夺用户。据 WSJ 援引知情人士报道，讨论仍在进行中，尚未最终确定。

## 背景

- OpenAI 已于 6 月初秘密提交 IPO 申请
- Anthropic 同样在推进 IPO 进程
- Claude Fable 5（Mythos 级）6/9 公开发布后，Anthropic 用户增长势头强劲
- 两家公司都在争夺企业和开发者市场

## 对 ZhouXuan 的影响

- 当前主力 API：DeepSeek（本身已是低价路线）
- 若 OpenAI 大幅降价，可能引发连锁反应：DeepSeek 可能跟进降价以维持性价比优势
- Anthropic 若被迫应战，Claude API 使用成本可能下降
- 关注后续 DeepSeek 是否调整定价策略
