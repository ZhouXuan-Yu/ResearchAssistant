## 核心发布

智源研究院院长王仲远在 2026 智源大会上发布两大世界模型：

### 悟界·Physis-v0.1 — 全球首个通用世界基座模型

- **核心范式**：「下一物理状态预测（Next Physical State Prediction）」
- 不再依赖传统像素、视频帧或动作序列预测，而是通过物理隐空间表征学习真实世界运行规律
- 将视频、RGB-D、3D 点云、力触反馈等多模态信息统一编码为「物理状态 Token」
- 支持 50+ 复杂物理场景的长程推演与泛化应用
- 四大核心能力：物理一致性、动作灵活性、长程可推演、通用泛化性
- 未来几个月内开源
- 负责人：陈博远（逆矩阵科技创始人，ACL 2025 最佳论文，谷歌学术 2300+ 引用）

### 悟界·RoboBrain Orca-v0 — 具身大脑

- 构建「统一表征 → 建模 → 预测 → 交互」完整闭环
- 以统一物理状态表征替代字符/像素/动作分立预测
- 同时生成语言思考、视觉预测与动作决策
- 已与 50+ 家企业合作

### 同期发布

- **悟界·Brainμ 1.0**：全球首个多模态神经科学大模型（Next-Token Prediction 扩展到神经科学），Science 正刊发表
- **悟界·OpenComplex 2.5**：AI 药物发现，单一模型覆盖制药四大关键步骤

> 2023 智源大会：Yann LeCun 阐述新一代世界模型概念

核心范式迁移：
```
Next Token → Next Frame → Next Action → Next State（物理状态）
```

## 为什么重要

1. **范式跃迁**：从「预测下一个词」到「预测世界下一状态」，是从语言模型到世界认知的根本转变
2. **物理一致性**：主流 AI 模型不懂真实物理规则、推演可信度低、长程记忆缺失 — Physis 瞄准这三个核心短板
3. **开源承诺**：延续 BAAI 系列开源传统（Emu3.5 已 Apache 2.0），Physis 也将开源
4. **中国 AI 路线**：BAAI 这条世界模型路线与 OpenAI/Anthropic/Google 的 LLM 主导路线形成差异化路径
