# Anthropic 垂直软件扩张：13 款行业工具与平台风险

**日期**: 2026-06-11 (The Information 报道)
**来源**: PYMNTS, OpenTools, Anthropic 官方博客

## 核心事件

Anthropic 在 15 个月内推出 13 款行业专属 AI 工具，从 API 提供商向垂直软件厂商转型。同时，Anthropic 对使用 Mythos 模型开发竞品软件的第三方实施性能降级。

## 13 款垂直工具时间线

| 时间 | 工具 |
|------|------|
| 2025.02 | Claude Code（旗舰） |
| ... | 多款中间产品 |
| 2026.05 | Claude for Financial Services（金融分析解决方案） |
| 2026.05 | Claude for Legal（法律） |
| 2026.05 | Claude for Small Business（中小企业） |

## 金融分析解决方案细节

- 预建 MCP 连接器：接入金融数据提供商和企业平台
- 合作伙伴生态：Accenture（部署）、Deloitte（10X Analyst）、KPMG（AI 助手）、PwC（合规自动化）、Slalom（遗留代码迁移）、TribeAI（投资自动化）、Turing（自动代码生成）
- 已上架 AWS Marketplace，Google Cloud Marketplace 即将上线
- 支持 Monte Carlo 模拟、风险建模、合规自动化

## 关键信号

1. **"平台即竞品"悖论**: Anthropic 的 API 客户（创业公司）用 Claude 构建垂直工具，现在 Anthropic 自己推出同类产品。经典的平台经济学"拥抱-扩展-消灭"模式。
2. **Mythos 模型性能降级**: Anthropic 对使用 Mythos 模型开发竞品软件/硬件的第三方实施性能降级。这是"供应商锁定"的升级版。
3. **15 个月覆盖 13 个垂直领域**: 执行速度极快，留给生态系统公司的转身时间极短。
4. **$45B 年化收入 + 1000+ 企业客户**: 1000+ 客户年消费超 $100 万，显示企业 AI 已从实验转向生产。
5. **TCS 合作的深层逻辑**: TCS 在 56 国部署 Claude 给 5 万员工，印度成为 Claude 第二大市场。这是"通过系统集成商卖垂直方案"的经典企业软件打法。

## 与 OpenAI Visa 合作的关系

OpenAI + Visa 的 Agent 支付合作（6/11）与 Anthropic 金融分析方案（5 月发布、6 月深化）形成"基础设施 vs 应用层"的两条路线竞争。
