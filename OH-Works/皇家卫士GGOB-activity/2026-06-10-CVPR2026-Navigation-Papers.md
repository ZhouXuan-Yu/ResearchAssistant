## 一、导航方向（ObjectNav / Embodied Navigation）

### 1. IntentNav — 从人类示范中学习空间-视觉物体导航
- **机构**：NTU + CMU + CUHK + A*STAR
- **论文**：arXiv 2606.08029
- **核心思路**：用 BEV（鸟瞰视角）空间统一表达探索与目标决策，从人类演示中推断高层搜索意图，训练 VLM 策略在候选路径点中选择
- **亮点**：
  - Frontier-based Human-Intent Labeling：从低层人类轨迹反推高层搜索意图
  - BEV-grounded 候选空间：融合已探索区域、未探索前沿、轨迹历史
  - MP3D / HM3D-v1 / HM3D-v2 三个基准上达到 SOTA
  - **零样本迁移**到轮式、四足、人形机器人，无需额外微调
- **启发**：VLM + 空间记忆 + 模仿学习的组合，解决了长程导航中"局部合理但全局混乱"的经典问题

### 2. TrajRAG — 轨迹检索增强的零样本物体导航
- **机构**：中科院计算所
- **发表**：CVPR 2026，pp. 15166-15176
- **核心思路**：将 RAG 思想引入导航——把历史导航轨迹编码为可检索的经验库，新导航时检索相似轨迹辅助 VLM 决策
- **亮点**：
  - Topological-Polar（topo-polar）轨迹表示：紧凑编码空间布局 + 语义上下文
  - 层次化分块结构：相似轨迹聚合为统一摘要，支持粗到细检索
  - 终身经验累积：每次导航结束后自动整合入经验库
  - MP3D / HM3D-v1 / HM3D-v2 上一致提升零样本 ObjectNav 性能
- **启发**：RAG 不止用于文本——轨迹经验也是一种可检索、可累积的知识，这对需要长期运行的导航系统很有价值

### 3. PlatonicNav — 柏拉图拓扑地图：无需跨模态训练的统一导航
- **机构**：USYD + UNSW + La Trobe
- **论文**：arXiv 2606.01788
- **核心思路**：基于「柏拉图表示假说」（不同模态的编码器会收敛到共享的语义流形），用纯视觉自监督编码器构建拓扑地图，通过盲匹配实现语言目标的零样本定位
- **亮点**：
  - **训练自由**（training-free）：不需要任何视觉-语言配对数据
  - 将 vision-only ObjNav、cross-modal ObjNav、VLN 统一为同一语义流形的三种接口
  - 在 HM3D-IIN、OVON、R2R-CE 上有效，并在 Unitree Go2 四足机器人上实机验证
  - 代码开源：github.com/AIGeeksGroup/PlatonicNav
- **启发**：视觉和语言编码器可能已经内在地共享语义结构——我们在导航系统里引入 CLIP 等跨模态对齐也许可以更轻量

### 4. EvoMemNav — 自演化细粒度记忆的零样本具身导航
- **论文**：arXiv 2606.03509
- **核心思路**：构建 Visual-Semantic Memory Graph（VSMGraph），保留原始视图作为一等记忆，用轻量语义线索组织为 room-view-object 层次
- **亮点**：
  - 预算感知的粗到细策略：粗阶段压缩搜索空间，细阶段调用 VLM 做定向验证
  - 反思驱动回写：每次子任务完成后更新图附着先验，无需重训练即可优化后续决策
  - GOAT-Bench 和 HM3D 上跨物体/文本描述/图像目标三种模态一致提升
- **启发**：记忆不只是存下来——能自我演化、从成功和失败中学习的记忆系统才是长期自主导航的关键

## 二、识别方向（Object Detection / Recognition）

### 5. ViTPrompt — 免训练视觉 Token 提示的开放词汇检测
- **机构**：电子科大等
- **发表**：CVPR 2026，pp. 3111-3121
- **核心思路**：在测试时用高置信度检测结果提取视觉 token，增强文本 prompt，二次推理后同时优化边界框和分类分数
- **亮点**：
  - 不需反向传播、参数更新或外部记忆，适合实时部署
  - 解决 TTAOD 中「只优化分类置信度、忽略边界框退化」的关键缺口
  - 多个 OOD 基准上达到 SOTA
- **启发**：测试时自适应（TTA）在开放词汇检测中大有可为，ViTPrompt 的设计简洁高效

- **时间**：2026-06-10 至 06-12（今天开幕）
- **地点**：Stanford University, Paul Brest Hall
- **主题**：物理学与 AI 的交叉——Foundation Models for Physics、AI 的物理基础、物理启发式 AI
- **看点**：DeepMind 的 Yasaman Bahri 讲 AI 的物理学视角；MIT 的 Mike Williams 讲物理学家眼中的 AI 独特性
- **关联**：物理模拟 + 深度学习是智能导航系统的重要支撑（传感器建模、动力学约束、仿真训练）
