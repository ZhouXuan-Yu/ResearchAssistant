# OpenAI Dreaming V3：ChatGPT 记忆系统全面重构

**日期**: 2026-06-04
**来源**: OpenAI 官方博客, The Verge, Krasa.ai, EdTech Innovation Hub

## 核心事件

OpenAI 推出 Dreaming V3，ChatGPT 记忆系统自 2024 年以来最大一次重构。首次面向免费用户开放自动记忆合成功能。

## 演进路线

| 版本 | 时间 | 能力 |
|------|------|------|
| Saved Memories | 2024 | 用户显式要求记住 |
| Dreaming V0 | 2025.04 | 后台自动从对话历史中提取记忆（仅付费） |
| Dreaming V3 | 2026.06 | 记忆自动衰减+更新+免费开放 |

## V3 核心创新

1. **记忆自动衰减与更新**: 记忆不再是静态快照，而是随时间自然淡出和刷新。"你7月2日搬家"这类时间敏感信息会自动更新，而非永远停留在旧状态。
2. **三维优化**: 新鲜度（freshness）、连续性（continuity）、相关性（relevance）
3. **计算成本降低 5x**: 使免费用户开放成为可能
4. **记忆容量翻倍**: Plus/Pro 用户获得双倍存储空间
5. **记忆摘要页**: 用户可查看、编辑、删除 ChatGPT 对自己的认知

## 性能数据

- 任务成功率从 2024 年的 31.4% 提升至 2026 年的 82.8%
- 256K 上下文窗口支持（600 页文档）

## 重要信号

1. **免费开放的战略意图**: 降低计算成本 5x 后向免费用户开放，是 OpenAI 在记忆功能上的"Android 式"渗透策略。数百万人将在无感知中被自动记忆合成。
2. **EU AI Act 合规压力**: 2026 年 8 月生效的欧盟 AI 法案透明度规则要求用户画像可审计。OpenAI 提前开放记忆控制面板可能是为合规铺路。
3. **"Dreaming" 的隐喻**: 名字本身暗示 AI 在"做梦"时整理记忆，与人类睡眠中的记忆巩固机制类比。这是技术品牌化的精妙一击。
4. **与 HanaAgent 记忆系统的对比**: HanaAgent 的 pinned memory + session memory 是显式、手动的；Dreaming V3 是隐式、自动的。两种范式代表了 AI 助手记忆的不同哲学。
